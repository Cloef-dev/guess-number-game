# Guess Number Game 🎯

A simple Python game where the computer generates a random number and the player tries to guess it.

## How it works
- The computer picks a random number
- The player tries to guess it
- The game gives hints like "too high" or "too low"

## What I learned
- Variables
- Loops (while True)
- If/else conditions
- User input

## How to run
Run the Python file in Pydroid 3 or any Python environment.
